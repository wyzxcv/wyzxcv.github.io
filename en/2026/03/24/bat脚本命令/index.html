前言：

bat 脚本是 Windows 自带的脚本，非常适合用来自动化重复性操作，比如一键备份文件、批量重命名、启动多个程序等；它的语法简单，无需安装任何额外环境，用记事本就能写。

常用命令

命令 作用
echo 输出信息 / 开启回显
@echo off 关闭回显
pause 暂停，显示“按任意键继续”
rem(::) 注释（不执行）
set 定义/显示变量
%变量名% 使用变量
if 条件判断
for 循环
cd 切换目录
dir 列出文件
copy/xcopy/robocopy 复制文件/目录
del 删除文件
md/mkdir 创建目录
rd/rmdir 删除目录
start 启动程序或文件
call 调用另一个 .bat
exit 退出
